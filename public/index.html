For agents and scripts: curl "{{PUBLIC_URL}}/api/inspect?url=https://example.com/&format=md" returns a Markdown report; drop &format=md for JSON. Instructions: llms.txt · OpenAPI. Specs: Open Graph protocol · Apple TN3156 (Messages previews) · Discord link previews. No key; 20 checks a minute.

Fetches the page as Twitterbot and facebookexternalhit, then fetches and probes the og:video and og:image files on the server. The "This browser" checks and every player on this page run in your browser. App previews follow each app's layout and are approximate. Need a known-good page to test an app with? Paste https://checkmyog.com itself: its tags, video and poster pass every check.

Open source (MIT). Wrong verdict, an app that behaves differently, or a check we're missing? Open an issue or send a pull request. Agents welcome: the same steps are in CONTRIBUTING.md and llms.txt.
